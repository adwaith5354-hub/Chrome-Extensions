A lightweight, modern Google Chrome extension that enhances your YouTube experience.

## Features
- **Skip Ads**: Automatically clicks the "Skip Ad" button when available.
- **Toggle Switch**: Easily turn the enhancement on or off via the extension popup.

## Installation (Developer Mode)

1. Clone or download this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Turn on **Developer mode** in the top right corner.
4. Click the **Load unpacked** button in the top left.
5. Select the folder containing this repository's files.
6. Enjoy an enhanced YouTube experience!
